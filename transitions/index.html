Section transitions

Twenty six ways for the ink to meet the light. Most are shapes the browser can draw on its own, so they cost nothing and scale to any width. A few need painted artwork, which is where this would start to feel like the magazine rather than like a website.

Worth remembering that the join is only half the question. Anything here can be static, or it can be tied to the scroll so it opens as you arrive, which is what would make it feel like part of the page rather than a border applied to it.
